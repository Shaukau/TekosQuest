# Tekos InfraQuest

Jeu RPG pédagogique consacré à la formation TSSR.

## Version publiée

V121.6 — Compatibilité carrière et tickets sur site.

## Lancement local

Ouvrir `index.html` dans un navigateur récent.

## Déploiement Vercel

1. Importer ce dépôt dans Vercel.
2. Choisir **Framework Preset : Other**.
3. Laisser la commande de build vide.
4. Laisser le dossier de sortie vide ou utiliser `.`.
5. Cliquer sur **Deploy**.

Chaque modification poussée sur la branche `main` déclenchera ensuite un nouveau déploiement.

## Sauvegardes

La progression est enregistrée dans le stockage local du navigateur. Elle reste liée au navigateur et au domaine utilisé.
